Capacidades Únicas

Diseñada para elevar tu flujo diario

Miku se integra orgánicamente en Windows con una isla discreta, automatización visual de tu ratón y la potencia de los mejores modelos del mundo.

Isla Dinámica Nativa

Ubicada discretamente en el notch superior. Se expande con suaves animaciones de resortes al reproducir Spotify, recibir alertas o ejecutar comandos.

Multi-Modelo con Auto-Respaldo

Gemini Flash Lite, Gemini 2.5 Pro, Claude 3.5 Sonnet, GPT-4o y Groq Whisper. Si una API se agota o satura, Miku conmuta al instante a tu clave de respaldo.

Computer Use & Memoria Espacial

Ve tu pantalla, analiza la interfaz y recuerda dónde hacer clic. Automatiza tareas en cualquier app de Windows sin requerir APIs complejas.

Creador de Agentes & MCP

Crea agentes especializados desde la interfaz o conecta herramientas de terminal (Claude Code, Cursor) usando webhooks y servidores MCP oficiales.

Música & Spotify Integrado

Detección automática de reproducción, carátula dinámica en la isla y control total por voz o atajos de teclado sin salir de tu ventana actual.

100% Local & Seguro

Tus credenciales y bases de datos se almacenan exclusivamente en tu equipo. Sin intermediarios, sin telemetría intrusiva, código abierto bajo MIT.

Ecosistema

Crea Agentes o Conecta tu Terminal

Extiende Miku como desees: mediante el creador visual o usando el hook de terminal para Claude Code y Cursor.

  • ✦ Creador No-Code en la App: Asigna prompt, servidor MCP y llaves dedicadas con un clic.
  • ✦ Hooks en Vivo: Recibe avisos en la Dynamic Island cuando tu agente termine una compilación o requiera permisos.
  • ✦ Protocolo MCP: Conecta bases de datos SQLite, Google Drive y el sistema de archivos local de forma segura.
Terminal / Claude Code Hook 
# 1. Notificar a Miku de una tarea en terminal
python scripts/miku_hook.py "Refactorizando servidor..." --event PreToolUse

# 2. Solicitar permiso visual en la Dynamic Island
python scripts/miku_hook.py "¿Borrar directorio dist/?" --event PermissionRequest

# 3. Notificar finalización exitosa
python scripts/miku_hook.py "¡Compilación completada!" --event Stop
