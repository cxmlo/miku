# Carpeta de Sonidos Personalizados de Miku

Coloca aqui tus archivos de sonido en formato WAV o MP3 para reemplazar los sintetizadores de audio WebAudio del sistema:

- `click.mp3` o `click.wav`: Sonido de pulsacion de botones y pestañas
- `notification.mp3` o `notification.wav`: Notificaciones entrantes de agentes y alertas
- `success.mp3` o `success.wav`: Tarea completada con exito
- `alert.mp3` o `alert.wav`: Avisos de confirmacion y advertencias de seguridad
- `update.mp3` o `update.wav`: Anuncio de nueva version o actualizacion disponible

Si un archivo no esta presente en esta carpeta, el sistema utilizara automaticamente la sintesis procedural WebAudio de alta fidelidad con atenuacion dinamica (audio ducking al 20%).
